## 二、整体印象

先说结论：**骨架是对的，桥段是好的，问题在句子的密度和几处说明体。** 几年前的稿子能有这个结构，本来就不容易。

### 立得住的东西（改稿时一根手指都不要碰）

1. **物件贯穿。** 瓶装甜咖啡（未名在警署喝到的那瓶）→ 枢环边缘最后半瓶 → 盒装咖啡 → 几千年后为饮品厂推商业政策。大角星"在谁的眼睛里见过" → 夜之海边"第一亮星"。发带（未名系的蝴蝶结）→ 舞会上的绿发带 → 内战时给平民止血。勿忘我 → 沈禹之从她发间取下的花瓣 → "这是重要的礼物"。这些线全都收回来了，一个都没丢。
2. **约稿单指定的桥段全在，而且每个都比约稿单写得更好。** 割手改成加油站卫生间割腕、未名冲水掩盖血迹，比约稿单的版本重；"难道你喜欢我？/没有"之后接"他想倒转时间回到一分钟前称是"；"我会成全你"前面铺了里庚初那一整场。
3. **未名君的声口是对的。** "我叫庚初""恩菲尔陛下万岁""我可是扣扳机的高手""主角的发型从来不会变乱""我要把你挂在二手网站里卖个好价钱"。贱兮兮、嘴碎、靠谱，一个不少。
4. **XIV 越野车被炸**，767 字，追兵杀错人，只留一句"不是目标人物，继续追踪"。全篇最狠的一节。
5. **XXIV 的 α/β 交替**。恩菲尔找房卡那段（口袋空、想起衣服在洗衣机里、跑回去拿）是真实的慌。
6. **XXV 结尾**。"我只是不再束缚你了"→ 血 → 梦醒 → 碎纸机。收得住。庚初"我的爱不比你少/至少我曾表明心意"这两句对话很妙。
7. **"神迹在一个没做干湿分离的洗手间里"** 这种自嘲式的落点，是几年前就有的、现在《雨中》里也有的东西。

### 要动的地方

**1. 句子密度（最大的一项，贯穿全篇）。**
- 连接词高频：便 185 次、于是 62、实则 20、无疑 17、堪称 11。几乎每段都有"于是……便……"的推进感，读久了像在被人牵着走。
- 比喻叠加："像是……般""像只……"（5 次）、"变魔术般"（3 次）、"眉眼弯弯"（5 次）、"不置可否"（4 次）、"从善如流"（3 次）。
- 内心活动全部写出来。恩菲尔每次脸红，后面都跟一句解释这是什么情绪（"这份情绪名为'受宠若惊'、或是'羞赧'"）。《雨中》的做法是不解释，让霉菌自己长。这篇很多地方可以把解释删掉，让动作自己说。
- 对策：逐节做减法，目标是总字数不变或略减，但每句的重量上去。不换骨架。

**2. 枢环弧线（Ⅴ-Ⅹ）偏长、未名偏被动。** 医院垄断 → 烧仓库 → 黑帮搜查 → 流浪汉揭底 → 暴动，六节三万字里未名大半时间在当观众（数钱、吃蛋糕、画路线）。而且结局靠流浪汉一段独白把所有伏笔解释完（暖炉、信封、邮差）。可以压掉一到两千字，把几处说明变成动作，让未名在其中多做一件事。

**3. 说明体段落。** XXI 开头关于万世俱乐部与沈书记的政治关系、XIII 中段关于追兵与万世俱乐部的制衡、XXII 整节神谕机制。这些是作者在跟读者交代规则，可以拆散揉进对话或删。

**4. XIX 夜之海一场，少了约稿单里最好的一句。** 约稿单：未名"声音带着哭腔"问"这一路上的经历和行动还是没让你的火重新燃起来吗"。原稿里未名是默默哭，没问出口。这句该还回去，它是全篇的题眼。

**5. XVII 倒叙。** 拷问室醒来 → 中间插一大段"事情是这样发生的"麻醉气回放 → 再回到拷问室。回放段落是纯说明。建议改成恩菲尔在拷问室里断续想起，或干脆按时间顺序写。

**6. 恩菲尔的内心太直白。** "他爱慕她""他不想管那叫爱，尽管那可能是爱"这一类句子出现得早（XIII）。以恩菲尔的怂，前半段应该连"爱"这个字都不肯在心里说。可以让这个字晚一点出现，比如夜之海之后。

**7. 小处不一致。**
- "哈伦恩小姐"（XXI）：文中解释为旅店登记名，与约稿单一致，保留即可，但改稿时确认老板是否还要这个名字。
- "齐殊辰"（Ⅴ，警署新人时期的本名）只出现一次，是个好设定，可以在 XXV 再点一次。
- 根环出现"皇族势力"的酒馆（XV），与三环设定不搭，改成"枢环势力"或删。
- 里庚初在 XIX 的口吻偏"讲道理"，可以更刻薄一点，贴近设定里"傲慢又毫不留情"。

## 四、建议的改稿顺序

1. **先不换性别，先打磨。** 逐节做减法 + 修说明体 + 还回题眼句。这一轮结束时稿子还是 BG，但已经是"打磨过的 BG"。
2. **再统一转 GL。** 那时句子已经定型，改人称不会和改句子互相干扰。
3. **最后过一遍两个"她"的辨识度**，确保任何一段单独拿出来都知道谁是谁。

每节改完给宁宁看一次，她拍板再往下走。
